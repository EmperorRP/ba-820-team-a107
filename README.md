# BA820 – Project Proposal  
## European Drug Development & U.S. Government Grant Opportunities

This repository contains the exploratory data analysis (EDA) and supporting materials for our BA820 Project Proposal. The project explores structural patterns in two high-stakes decision contexts: pharmaceutical regulatory approval in Europe and U.S. federal grant opportunities.

The goal of this phase is to conduct preliminary EDA to motivate insight-driven, unsupervised learning questions, not to develop final models.

---

## Repository Structure

### 📁 data/
Contains the datasets used in the project:
- `drugs.csv` – European Medicines Agency drug development and regulatory outcomes dataset  
- `grants.csv` – U.S. federal grant opportunities from Grants.gov  
- `grant_opportunity_details.csv` – Detailed grant-level metadata, including eligibility and funding structure

---

### 📁 notebooks/
Contains individual exploratory data analysis notebooks contributed by each team member based on either **m1** or **m2** which are available in its own directory:

- `Keane_Drug_and_grant_EDA.ipynb`
- `alex_grant_EDA.ipynb`
- `alex_medicines_EDA.ipynb`
- `brian_drugs_eda.ipynb`
- `brian_grants_eda.ipynb`
- `rahul_eda.ipynb`

Each notebook focuses on exploratory analysis, pattern discovery, and hypothesis generation to support the project proposal.
